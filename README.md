# Баббл Муун Тии — концепт сайта

Статичный сайт: `index.html`, `style.css`, `script.js`, шрифты `*.woff2`, логотип и фото. Все файлы лежат в одной папке, загружать в корень репозитория.

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что сверить с кофейней
- Часы работы: на двери и в Яндексе 08:00–20:00, в ВК — будни 9:00–21:00, выходные 10:00–21:00. На сайте стоит 08:00–20:00.
- Цены круассанов в меню нет — на слайде без цены.
- Фото взяты из их ВК / Яндекс Карт; для публичного портфолио — с их разрешения.
- Логотип используется как есть; новых изображений персонажа с логотипа не добавлено.
